# Personal Portfolio

A modern and responsive developer portfolio built with React and Vite to showcase my projects, skills, and contact information.

## Live Demo

react-portfolio-swart-mu.vercel.app/

## Features

* Responsive design for all devices
* Modern and clean UI
* Projects showcase section
* Skills section
* Contact section
* Fast performance with Vite

## Projects Featured

### HireLog

A job application tracking dashboard built with React and Tailwind CSS.

**Key Features**

* Add, edit, and delete job applications
* Filter applications by status and priority
* Responsive user interface
* Local storage persistence

### TaskFlow Dashboard

A task and workflow management dashboard designed to improve productivity.

**Key Features**

* Create and organize tasks
* Update workflow status
* Responsive dashboard layout
* Component-based React architecture

## Tech Stack

* React.js
* Vite
* JavaScript
* HTML5
* CSS3

## Installation

```bash
git clone <repository-url>
cd portfolio
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
